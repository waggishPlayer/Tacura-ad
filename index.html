5 Modular Operating Modes

Cycled seamlessly using the dedicated Mode key on the 10-key GPIO chord keyboard.

📖

1. LEARN Mode

Guided Braille literacy. Displays alphabet letters sequentially on the haptic cell with synchronised high-definition neural speech synthesis.

LITERACY_ENGINE
🎮

2. QUIZ Mode

Gamified chord typing drills. Test tactile recognition and speed with interactive levels, streaks, scoreboards, and AI tutor audio encouragement.

GAMIFIED_PRACTICE
📝

3. NOTES Mode

Tactile digital notebook. Compose thoughts and notes directly using the 6-dot chord keyboard. Automatically saved to persistent storage.

DIGITAL_NOTEBOOK
🌐

4. WEB Mode

Voice-guided AI web assistant. Type queries in Braille; Tacura uses Groq (Llama 3.1) & Wikipedia to format concise 3–5 sentence audio summaries.

GENERATIVE_AI
🔊

5. READ Mode

Review saved notes letter-by-letter on the dynamic haptic display or listen to automated audio readbacks at customizable speeds.

PLAYBACK_MANAGER
